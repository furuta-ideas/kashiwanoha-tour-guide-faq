# あさちゃんコミュニケーションボード ＜Asa-Com＞ 仕様書

| 項目 | 内容 |
| --- | --- |
| アプリ名 | あさちゃんコミュニケーションボード（Asa-Com） |
| 版数 | Rev.1（初版） |
| 作成日 | 2026-09-09 |
| 想定プラットフォーム | iPad（Safari / ホーム画面へ追加によるフルスクリーン起動） |
| 実装形態 | HTML5 単一ファイル（`asa-com.html`）／外部依存なし・オフライン動作 |
| デザインシステム | Google Material Design 3（M3）準拠、シンプル＋親しみやすさ |

---

## 1. 目的と背景

発話や細かな手指操作が困難な利用者（以下「本人」）が、**iPad のアクセシビリティ機能**（頭部の動き・視線の動き・指先のタップなど）を使って、介助者・家族へ意思を伝えるための意思伝達（AAC: Augmentative and Alternative Communication）アプリ。

- 本人は「選ぶ」だけで意思を伝えられる
- 介助者はやりとりの履歴（ログ）を見返せる／記録として残せる
- 段階的な難易度（レベル1〜3）で、本人の状態に合わせて選択肢の数を変えられる

### 1.1 設計上の基本方針

1. **誤操作より無操作を優先** — 意図しない選択が起きないよう、確定には滞留（ドウェル）時間を設ける
2. **大きく・少なく・はっきり** — ターゲットは極力大きく、色と文字で二重に区別する
3. **常に元に戻れる** — 選択後は必ず取り消し可能な猶予を用意する
4. **単一画面で完結** — モーダルやページ遷移を最小化し、迷子にならない
5. **ネットワーク不要** — 通信環境に依存せず、病室・在宅・外出先で使える

## 3. アプリのレベル構成

本人の状態・習熟度に応じて、3つのレベルを切り替えて使用する。

### レベル1：2択

| 位置 | 選択肢 | 用途 |
| --- | --- | --- |
| 左 | **はい** | 肯定 |
| 右 | **いいえ** | 否定 |

- 選択エリアを**縦2分割**（左右2列）
- 添付の画面設計図に対応する基本形

### レベル2：3択

| 位置 | 選択肢 |
| --- | --- |
| 左 | **はい** |
| 中 | **いいえ** |
| 右 | **どちらでもない** |

- 選択エリアを**縦3分割**（左右3列）

### レベル3：6択

選択エリアを **3列 × 2行 の6分割**（横長のiPad画面で1枚あたりの面積を最大化するため）。

| | 左列 | 中列 | 右列 |
| --- | --- | --- | --- |
| **上段** | はい | いいえ | どちらでもない |
| **下段** | 音楽かけて | 体痛い・痒い | 暑い・寒い |

#### レベル別 選択肢マスタ

| ID | ラベル | アイコン（M3 Symbols） | 使用レベル |
| --- | --- | --- | --- |
| `yes` | はい | `check_circle` | 1 / 2 / 3 |
| `no` | いいえ | `cancel` | 1 / 2 / 3 |
| `neutral` | どちらでもない | `remove_circle` | 2 / 3 |
| `music` | 音楽かけて | `music_note` | 3 |
| `pain` | 体痛い・痒い | `healing` | 3 |
| `temp` | 暑い・寒い | `thermostat` | 3 |

> レベル切替はレベル1→3で選択肢が**追加される**方式とし、`yes` / `no` の位置は全レベルで左上固定とする（学習した位置を崩さないため）。

## 4. 画面レイアウト

### 4.1 全体構成（横向き固定を推奨）

```
┌──────────────────────────────────────────────────────────────┐
│ Asa-Com                                          （ヘッダー） │
├─────────────────────────────────┬────────────────────────────┤
│                                 │  10:15                     │
│                                 │    はい                    │
│        選 択 エ リ ア           │                            │
│                                 │  10:17                     │
│        （画面幅の 5/7）         │    いいえ         ログ     │
│                                 │                   エリア   │
│    ┌──────────┬──────────┐      │  10:19          （2/7）    │
│    │  はい    │  いいえ  │      │    はい                    │
│    └──────────┴──────────┘      │                            │
│                                 ├────────────────────────────┤
│                                 │        🎤 ON  │  📝 ON     │
└─────────────────────────────────┴────────────────────────────┘
```

| 領域 | 幅 | 内容 |
| --- | --- | --- |
| 選択エリア | 画面幅の **5/7**（約71.4%） | レベルに応じた選択ボタン |
| ログエリア | 画面幅の **2/7**（約28.6%） | やりとりの履歴（新しいものが下、自動スクロール） |
| コントロールバー | ログエリア下端に固定 | マイクON/OFF、ログON/OFF のトグルアイコン |

- CSS Grid で `grid-template-columns: 5fr 2fr;` を基本とする
- 選択エリアは `100dvh` から ヘッダー高を引いた高さいっぱいを使用
- ヘッダーはタイトル（Asa-Com）＋右端に設定ボタン（`⋮`）のみの薄いバー（高さ 56px）

### 4.2 選択エリア

- レベル1：`grid-template-columns: 1fr 1fr;`
- レベル2：`grid-template-columns: 1fr 1fr 1fr;`
- レベル3：`grid-template-columns: repeat(3, 1fr); grid-template-rows: 1fr 1fr;`
- ボタン間のギャップ：8px（誤選択防止のため隣接させない）
- ボタン内は **アイコン（上）＋ラベル（下）** の縦積み中央揃え
- ラベル文字サイズ：レベル1 = 96px / レベル2 = 80px / レベル3 = 48px（`clamp()` で画面サイズに追随）

### 4.3 ログエリア

- 1件の表示形式：

  ```
  10:15
    はい
  ```

  - 1行目：時刻（`HH:MM`、12px、グレー `#5F6368`）
  - 2行目：発言内容（20px、`#202124`、左に 16px インデント）
- 発話者による区別
  - **本人の選択** … 選択肢の色に対応した左ボーダー（4px）
  - **音声入力（介助者）** … 左ボーダーはグレー、末尾に `🎤` の小アイコン
- 最新が下に追加され、自動で最下部までスクロール
- 保持件数：画面上は直近 200 件（それ以前はメモリ上のみ保持しファイル出力対象）
- ログエリアはスクロール可能（`overflow-y: auto`、慣性スクロール有効）

### 4.4 コントロールバー

ログエリアの下端に固定配置。円形のトグルボタン2つ。

| ボタン | ラベル | ON時 | OFF時 |
| --- | --- | --- | --- |
| マイク | `マイク ON` / `マイク OFF` | Google Blue `#1A73E8` 塗り＋白アイコン | グレー枠 `#DADCE0`＋グレーアイコン、アイコンに斜線 |
| ログ | `ログ ON` / `ログ OFF` | Google Blue `#1A73E8` 塗り＋白アイコン | グレー枠 `#DADCE0`＋グレーアイコン、アイコンに斜線 |

- サイズ：直径 64px（介助者が操作する前提だが、誤タップを避けるため本人の選択エリアからは離す）
- 状態は `localStorage` に保存し、次回起動時に復元

## 5. 機能仕様

### 5.1 選択（意思伝達）

| 項目 | 仕様 |
| --- | --- |
| 入力手段 | タップ／iPadのAssistiveTouch（頭部トラッキング）／視線制御（対応デバイス）／スイッチコントロール |
| 確定方式 | **ドウェル確定**：ボタン上にポインタ／フォーカスが留まると確定リングが進行し、既定 **1.5秒** で確定 |
| ドウェル時間 | 設定で 0.5 / 1.0 / 1.5 / 2.0 / 3.0 秒 から選択（既定 1.5秒） |
| 直接タップ | ドウェルを待たず即確定（設定でタップ即確定を無効化可能） |
| 選択時フィードバック | ①ボタン色反転＋拡大アニメ（150ms） ②効果音（設定でOFF可） ③音声読み上げ（Web Speech Synthesis、日本語、設定でOFF可） |
| 取り消し | 確定後 **5秒間**、選択ボタン上に「とりけす」の小ボタンを表示。押すと直前のログを削除 |
| 連続誤操作防止 | 確定後 **1.0秒** は全ボタンを非活性（クールダウン） |
| スイッチコントロール対応 | 全ボタンに `tabindex` を設定し、フォーカスリング（4px、`#1A73E8`）を明示。Space / Enter で確定 |

#### ドウェル進行の表示
ボタン外周を囲む円弧（またはボタン枠を左→右へ塗る進行バー）でカウントダウンを可視化する。進行中に対象から外れた場合は即座にリセット。

### 5.2 音声入力（「ヘイ！あさちゃん」）

介助者の発話や、本人が発話可能な場合の補助入力として使用する。

| 項目 | 仕様 |
| --- | --- |
| ウェイクワード | **「ヘイ！あさちゃん」**（表記ゆれ許容：`ヘイあさちゃん` / `へいあさちゃん` / `hey あさちゃん` / `ヘイアサちゃん` 等を正規化して判定） |
| 動作 | ウェイクワード検出後、**15秒間**だけ音声入力を受け付ける |
| 15秒経過後 | 自動的に入力を締め切り、認識結果をログに1件追加。ウェイクワード待受状態に戻る |
| 待受 | マイクONの間、Web Speech API を継続認識（`continuous: true`）でウェイクワードのみ監視。ウェイクワード以外の発話はログに記録しない |
| 表示 | 受付中は選択エリア上部に「聞いています… 残り 12秒」のバナー＋残り時間バー（Google Blue）を表示 |
| 手動起動 | コントロールバーのマイクアイコンを長押し（1秒）でウェイクワード無しに15秒受付を開始 |
| 途中終了 | 認識結果が確定し、無音が 2秒続いた時点で 15秒を待たず締め切る |
| マイクOFF時 | ウェイクワードを呼びかけても**一切反応しない**（認識エンジン自体を停止） |
| 認識言語 | `ja-JP` |
| 非対応ブラウザ | Web Speech API 非対応時はマイクアイコンを非活性にし、「このブラウザでは音声入力は使えません」とツールチップ表示 |

> **注意**：iPadOS Safari では Web Speech API の音声認識に制限がある場合がある。実装時は機能検出（`window.SpeechRecognition || window.webkitSpeechRecognition`）を行い、非対応時も選択機能のみで完全に動作すること。

### 5.3 ログ

| 項目 | 仕様 |
| --- | --- |
| 記録内容 | 日時（ISO 8601）、表示時刻（HH:MM）、種別（`choice` / `voice`）、選択肢ID または 認識テキスト、レベル |
| 保存先 | `localStorage`（キー：`asacom.log`）に随時追記。日付ごとに区切る |
| ログOFF時 | ①ログエリアに表示しない ②`localStorage`へ保存しない ③ファイル書き出し対象にしない（＝その間のやりとりは一切残らない） |
| ログOFF中の表示 | ログエリアに「ログはOFFです」のプレースホルダを中央に淡色表示 |
| ファイル出力 | 設定メニューから「ログを書き出す」。CSV または テキスト形式でダウンロード（`Blob` + `<a download>`） |
| ファイル名 | `asacom_log_YYYYMMDD.csv` |
| 消去 | 設定メニューから「ログを消去」（確認ダイアログあり） |

#### CSV フォーマット

```csv
datetime,time,type,label,level
2026-09-09T10:15:32+09:00,10:15,choice,はい,1
2026-09-09T10:17:04+09:00,10:17,choice,いいえ,1
2026-09-09T10:19:41+09:00,10:19,voice,お茶飲む？,1
```

### 5.4 設定メニュー

ヘッダー右端の `⋮` から開く（本人の誤操作を防ぐため、**1秒長押し**で開く仕様とする）。

| 設定項目 | 選択肢 | 既定 |
| --- | --- | --- |
| レベル | 1 / 2 / 3 | 1 |
| ドウェル時間 | 0.5 / 1.0 / 1.5 / 2.0 / 3.0 秒 | 1.5秒 |
| タップ即確定 | ON / OFF | ON |
| 効果音 | ON / OFF | ON |
| 読み上げ | ON / OFF | ON |
| 読み上げ速度 | 遅い / ふつう / 速い | ふつう |
| 文字サイズ | 標準 / 大 / 特大 | 標準 |
| ハイコントラスト | ON / OFF | OFF |
| ログを書き出す | （実行） | — |
| ログを消去 | （実行） | — |

設定は `localStorage`（キー：`asacom.settings`）に保存。

## 6. デザイン仕様（Material Design 3 準拠）

### 6.1 カラートークン

| トークン | 値 | 用途 |
| --- | --- | --- |
| `--primary` | `#1A73E8`（Google Blue 600） | アクセント、ON状態、フォーカスリング |
| `--surface` | `#FFFFFF` | 背景 |
| `--surface-variant` | `#F1F3F4` | ログエリア背景 |
| `--outline` | `#DADCE0` | 区切り線、枠線 |
| `--on-surface` | `#202124` | 主要テキスト |
| `--on-surface-variant` | `#5F6368` | 時刻などの補助テキスト |
| `--yes` | `#34A853`（Google Green） | 「はい」 |
| `--no` | `#EA4335`（Google Red） | 「いいえ」 |
| `--neutral` | `#9AA0A6`（Grey） | 「どちらでもない」 |
| `--music` | `#FBBC04`（Google Yellow） | 「音楽かけて」 |
| `--pain` | `#F29900`（Orange） | 「体痛い・痒い」 |
| `--temp` | `#4285F4`（Google Blue 500） | 「暑い・寒い」 |

- 選択ボタンは**淡色の面（各色の 12% ティント）＋濃色の文字とアイコン**を基本とし、まぶしさを抑える
- 選択確定時のみ濃色に反転する
- コントラスト比は文字・アイコンともに **4.5:1 以上**（大きな文字は 3:1 以上）を確保

### 6.2 ハイコントラストモード

- 背景 `#000000` / 文字 `#FFFFFF` / 各選択肢は高彩度の原色ベタ塗り
- 枠線を 4px に強調

### 6.3 タイポグラフィ

| 用途 | フォント | サイズ | ウェイト |
| --- | --- | --- | --- |
| 選択肢ラベル | Noto Sans JP（フォールバック：`-apple-system`, `Hiragino Sans`） | `clamp(40px, 8vw, 120px)` | 700 |
| ログ本文 | 同上 | 20px | 500 |
| ログ時刻 | 同上 | 12px | 400 |
| ヘッダー | 同上 | 20px | 500 |

> Webフォントはオフライン動作を優先し、**システムフォント優先**とする（CDN読み込みは任意・失敗時もレイアウトが崩れないこと）。

### 6.4 形状・エレベーション

- 選択ボタン：角丸 **28px**（M3 Extra Large）、エレベーション Level 1（`0 1px 3px rgba(60,64,67,.3)`）
- コントロールボタン：完全な円形
- モーションは M3 標準イージング（`cubic-bezier(0.2, 0, 0, 1)`、150〜300ms）

### 6.5 レスポンシブ／iPad 最適化

| デバイス | 論理解像度（横向き） | 対応 |
| --- | --- | --- |
| iPad (10.9") | 1180 × 820 | 基準レイアウト |
| iPad Air (11") | 1180 × 820 | 基準レイアウト |
| iPad Pro 12.9" | 1366 × 1024 | 文字サイズを比例拡大 |
| iPad mini | 1133 × 744 | レベル3のラベルを1段階縮小 |

- ビューポート：`<meta name="viewport" content="width=device-width, initial-scale=1, viewport-fit=cover, user-scalable=no">`
- セーフエリア対応：`padding: env(safe-area-inset-*)`
- 縦向き（Portrait）時は選択エリアを上 5/7・ログエリアを下 2/7 に**縦積み**へ自動切替
- ピンチズーム・ダブルタップズーム・長押しの選択メニューを無効化（`touch-action: manipulation`、`user-select: none`）
- iOS の「ホーム画面に追加」でフルスクリーン起動（`apple-mobile-web-app-capable`）
- 画面のスリープ防止：`navigator.wakeLock`（対応時のみ）

## 7. iPad アクセシビリティ機能との連携

本アプリは iPadOS 標準のアクセシビリティ機能を前提とし、アプリ側では**それらが働く土台を整える**（独自のトラッキング実装は行わない）。

| iPadOS 機能 | 設定場所 | アプリ側の対応 |
| --- | --- | --- |
| AssistiveTouch + 頭部トラッキング | 設定 > アクセシビリティ > タッチ > AssistiveTouch > ポインティングデバイス | ポインタの `hover` を検出しドウェル進行を開始 |
| 視線制御（Eye Tracking, iPadOS 18+） | 設定 > アクセシビリティ > 視線制御 | 同上（OS側のドウェル、アプリ側のドウェルどちらでも確定できる） |
| スイッチコントロール | 設定 > アクセシビリティ > スイッチコントロール | 全ボタンをフォーカス可能にし、走査順を左上→右下に固定 |
| 保持継続時間（Dwell Control） | 設定 > アクセシビリティ > ポインタコントロール | アプリ側ドウェルと二重確定しないよう、アプリ側ドウェルはOFFにできる |
| アクセスガイド | 設定 > アクセシビリティ > アクセスガイド | 誤操作でアプリを抜けないよう、運用時の使用を推奨（マニュアルに記載） |

### 実装上の要点

- `pointerenter` / `pointerleave` / `pointermove` でドウェルを制御（マウス・トラックパッド・頭部トラッキングいずれも `pointer` イベントで統一的に扱える）
- `:focus-visible` で明確なフォーカス表示
- `aria-label` を全ボタンに付与、`role="log"` `aria-live="polite"` をログエリアに付与
- 誤って押しやすい領域（画面端 16px）にはボタンを配置しない

## 8. 技術仕様

| 項目 | 内容 |
| --- | --- |
| 実装 | HTML5 + CSS3 + Vanilla JavaScript（ES2020） |
| ファイル構成 | `asa-com/asa-com.html` 単一ファイル（CSS/JSインライン） |
| 外部依存 | なし（アイコンはインラインSVGで内包） |
| 音声認識 | Web Speech API（`SpeechRecognition` / `webkitSpeechRecognition`） |
| 音声合成 | Web Speech Synthesis API（`speechSynthesis`） |
| 永続化 | `localStorage`（設定・ログ） |
| ファイル出力 | `Blob` + `URL.createObjectURL` + `<a download>` |
| オフライン | 完全オフライン動作（音声認識のみOSの実装に依存） |
| 対応ブラウザ | iPadOS Safari 16+（主対象）、Chrome 90+、Edge 90+ |

### 8.1 データ構造

```js
// 設定
{
  level: 1,              // 1 | 2 | 3
  dwellMs: 1500,
  tapToConfirm: true,
  sound: true,
  speak: true,
  speakRate: 1.0,
  fontScale: 'normal',   // 'normal' | 'large' | 'xlarge'
  highContrast: false,
  micEnabled: true,
  logEnabled: true
}

// ログ1件
{
  id: 'a1b2c3',
  datetime: '2026-09-09T10:15:32+09:00',
  type: 'choice',        // 'choice' | 'voice'
  choiceId: 'yes',       // type==='choice' のとき
  text: 'はい',
  level: 1
}
```

## 9. 非機能要件

| 項目 | 要件 |

| 起動時間 | 2秒以内（オフライン、キャッシュあり） |
| 応答性 | 選択確定からログ表示まで 100ms 以内 |
| 連続稼働 | 8時間以上メモリリークなく動作 |
| プライバシー | 音声・ログは端末外へ一切送信しない（音声認識はOS/ブラウザ実装に準ずる旨をマニュアルに明記） |
| 電源 | 画面常時点灯を想定し、電源接続下での使用を推奨 |

## 10. 画面遷移

```
[起動]
   ↓
[メイン画面（レベルN）] ←─────────────┐
   │  ・選択 → ログ追加 → とりけす可能（5秒）
   │  ・「ヘイ！あさちゃん」→ 15秒受付 → ログ追加
   │                                   │
   └─ ⋮ 長押し → [設定シート] ──────────┘
                    ├─ レベル変更 → メインへ即反映
                    ├─ ログ書き出し → ファイル保存
                    └─ ログ消去 → 確認 → 実行
```

ページ遷移は発生しない（設定はボトムシート／モーダルで表示）。
