# あさちゃんコミュニケーションボード ＜Asa-Com＞

iPad のアクセシビリティ機能（頭部の動き・視線・指先のタップ）を使って意思を伝えるための
意思伝達（AAC）アプリ。**単一 HTML ファイル・外部依存なし・オフライン動作**。

| ファイル | 役割 |
| --- | --- |
| `index.html` | 配布物。これ1つで動作します |
| `SPEC.md` | 仕様書（Rev.1） |

## 公開URL

**https://furuta-ideas.github.io/kashiwanoha-tour-guide-faq/asa-com/**

## 使いかた

1. iPad の Safari で上記URLを開く（またはこの `index.html` を直接開く）
2. 共有メニュー → **ホーム画面に追加** でフルスクリーン起動になります
3. 初回は選択ボタンを1度タップしてください（iOS の制限で、最初の操作までは音声・効果音・画面スリープ防止が有効になりません）

## レベル

| レベル | 選択肢 |
| --- | --- |
| 1（2択） | はい／いいえ |
| 2（3択） | はい／いいえ／どちらでもない |
| 3（6択） | はい／いいえ／どちらでもない／音楽かけて／体痛い・痒い／暑い・寒い |

## 主な操作

| 操作 | 動作 |
| --- | --- |
| 選択ボタンをタップ | すぐ確定（設定でOFFにできます） |
| 選択ボタンにポインタ／視線を留める | **1.5秒**で確定（下端のバーが進みます。時間は設定で変更可） |
| 確定後5秒以内に「とりけす」 | 直前のログを取り消し |
| 「ヘイ！あさちゃん」と呼びかける | **15秒間だけ**音声入力がON |
| マイクアイコンをタップ | 音声入力の ON / OFF（OFFなら呼びかけても反応しません） |
| マイクアイコンを長押し（1秒） | 呼びかけなしで音声入力を開始 |
| ログアイコンをタップ | ログの ON / OFF（OFFなら表示も保存もされません） |
| 右上の ⚙ をタップ | 設定を開く |

## iPad 側の設定

| 使いたい操作 | iPad の設定 |
| --- | --- |
| 頭部の動き | 設定 > アクセシビリティ > タッチ > AssistiveTouch > ポインティングデバイス |
| 視線 | 設定 > アクセシビリティ > 視線制御（iPadOS 18以降） |
| スイッチ | 設定 > アクセシビリティ > スイッチコントロール |
| 誤ってアプリを抜けないように | 設定 > アクセシビリティ > アクセスガイド（使用中の固定を推奨） |

> iPad側の「保持継続時間（ドウェル）」を使う場合は、アプリ側の **滞留で確定** を OFF にすると
> 二重に確定しません。

## 設定でできること

右上の ⚙ から、5つのセクションで細かく調整できます。

| セクション | 調整できること |
| --- | --- |
| 選ぶ操作 | **滞留で確定の ON/OFF**、滞留時間（0.3〜5.0秒）、タップで即確定、「とりけす」を出す時間、連打よけの間隔 |
| 画面 | レベル（1〜3）、文字サイズ、ボタンの間隔、アイコン表示、ログ欄の幅（かくすも可）、ハイコントラスト |
| 音 | 効果音の ON/OFF と大きさ、読み上げの ON/OFF と速度 |
| 音声入力 | 「ヘイ！あさちゃん」で開始する／しない、受付時間（10〜30秒）、話し終わりで締め切るまでの秒数 |
| その他 | 使用中は画面を消さない、設定ボタンを長押しで保護 |

- 「滞留」と「タップ」を両方OFFにはできません（片方をOFFにすると、もう一方が自動でONに戻ります）
- 本人が誤って設定を開いてしまう場合は「**設定ボタンを長押しで保護**」を ON にしてください。1秒長押ししないと開かなくなります
- 「設定を初期値にもどす」でいつでも既定値に戻せます（ログは消えません）

## データの扱い

- 設定・ログは端末内（`localStorage`）にのみ保存され、外部へ送信されません
- 設定 > **ログを書き出す（CSV）** で `asacom_log_YYYYMMDD.csv` を保存できます
- 音声認識は端末／ブラウザ（Web Speech API）の実装に依存します

## 動作環境

- iPadOS Safari 16 以降（主対象）
- Chrome 90+ / Edge 90+
- 音声認識が使えない環境では、マイクボタンが「非対応」となり、選択とログの機能のみで動作します
