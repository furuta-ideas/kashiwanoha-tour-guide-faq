## 1. 目的と背景

発話が困難で、**指先で画面に文字を書くことはできる**利用者（以下「本人」）が、
iPad の画面に **1文字ずつ指で文字を書く**ことで意思を伝えるためのアプリ。

- 本人は「書く」→ アプリが読み取る → **その場で声になる**
- 「はい／いいえ」では伝えきれない言葉（固有名詞・数字・要望）を伝えられる
- 介助者はやりとりの履歴（ログ）を見返せる／記録として残せる

### 1.1 設計上の基本方針

1. **書いたらすぐ声になる** — カタカナ／数字と判断できた時点で即座に発音する（1文字ごと）
2. **待たせない** — 1文字ごとの確定ボタンは置かない。書き終わりを自動で判定する
3. **間違えてもすぐ戻せる** — ジグザグを描けば1文字消える（音声で「削除」と知らせる）
4. **単一画面で完結** — モーダルやページ遷移を最小化する
5. **ネットワーク不要** — 文字認識・音声合成ともに端末内で完結（オフライン動作）
6. **Asa-Com と同じ顔** — ヘッダー・ログ欄・コントロールバー・設定シートの構成を踏襲する

### 1.2 入力できる文字（本版の範囲）

| 種別 | 文字 | 入力方法 |
| --- | --- | --- |
| カタカナ 清音 | ア〜ン（46字） | 手書き |
| 長音符 | ー | 手書き（横1画） |
| 算用数字 | 0〜9 | 手書き |
| 濁音・半濁音 | ガ〜ポ | **［゛］［゜］ボタン**で直前の1文字を変換（案。第9章 Q2） |
| 小書き（拗音・促音） | ァィゥェォャュョッ | **［小］ボタン**で直前の1文字を変換（案。第9章 Q2） |
| 空白 | （半角スペース） | ［あける］ボタン（案） |

- **ひらがな・漢字・アルファベットは対象外**（本人がカタカナと数字のみを使うため）
- カタカナと数字は字形が重なるもの（例：`ロ`と`0`、`エ`と`工`相当の数字なし、`ニ`と`=`）があるため、
  第4章の「認識モード」で曖昧さを抑える

### 3.2 入力中の行

| 項目 | 仕様 |
| --- | --- |
| 表示 | 認識確定した文字を左から順に表示。末尾に点滅カーソル |
| 文字サイズ | `clamp(32px, 5vw, 72px)` / 太さ 700 |
| 長い場合 | 横スクロール（常に末尾が見える。自動スクロール） |
| 直前の1文字 | 認識直後 600ms だけ淡い青のハイライト（「いま読んだ文字」がわかる） |
| よみあげボタン | 行の右端。押すと**行全体**を読み上げる |
| 空のとき | 「ここに よんだ もじが でます」を淡色で表示 |

### 3.3 手書きキャンバス

| 項目 | 仕様 |
| --- | --- |
| マス | **1マス（1文字ずつ）**。中央に点線の十字ガイド、外周に実線の枠（`--outline`） |
| 実装 | `<canvas>`（`devicePixelRatio` 対応）。線幅 10px（設定で 太さ 細/中/太）、丸端、色 `--on-surface` |
| 入力イベント | Pointer Events（`pointerdown/move/up/cancel`）。`touch-action:none` |
| マルチタッチ | **最初の1点のみ**を筆として扱い、他の接触は無視（手のひら対策） |
| はみ出し | マス外に出ても描画は続行（座標は正規化時に吸収） |
| 書いた字の消去 | 文字が確定した瞬間にフェードアウト（200ms）して空になる |
| 書き直し | ジグザグ（削除ジェスチャ）で、書きかけの筆跡があればそれを破棄、無ければ確定済みの1文字を削除 |

### 3.4 補助キー行

| キー | 動作 | 発音 |
| --- | --- | --- |
| ［゛］ | 直前の1文字を濁音に変換（カ→ガ）。不可なら無効（淡色） | 変換後の文字（例「ガ」） |
| ［゜］ | 直前の1文字を半濁音に変換（ハ→パ） | 変換後の文字 |
| ［小］ | 直前の1文字を小書きに変換（ヤ→ャ、ツ→ッ）。もう一度押すと戻る | 変換後の文字 |
| ［ー］ | 長音符を追加（手書きでも入力可。押し間違い防止の保険） | 「ー」 |
| ［あける］ | 半角スペースを追加 | 無音 |
| ［← けす］ | 1文字削除 | 「削除」 |
| ［ぜんぶけす］ | 入力中の行を全消去（**1秒長押し**で実行、確認トースト） | 「ぜんぶ けしました」 |

> 補助キーは介助者・本人どちらも使える大きさ（高さ 56px、最小幅 96px）とし、
> キャンバスから 12px 離して配置する（書いている最中の誤タップ防止）。

### 3.5 ログエリア／コントロールバー

Asa-Com（選択版）4.4 / 4.5 と同一仕様。ただし：

| 項目 | Asa-Com2 での扱い |
| --- | --- |
| 記録単位 | **確定した1行（文）単位**（1文字ごとには記録しない。第9章 Q4） |
| 種別 | `text`（手書き入力）のみ。音声入力（🎤）は本版では非搭載 |

## 4. 文字認識

### 4.1 認識のタイミング（最重要）

「書き終えた瞬間に声になる」ことを最優先し、**画数の確定を待たずに**判定する。

```
1画書く → 書き終わり（pointerup）
   ├─ ジグザグ判定 → 該当すれば即「削除」（4.4）
   ├─ 認識を実行（いまの画数の筆跡すべてを使う）
   │    ├─ ① 1位候補のスコアが「即確定しきい値」以上
   │    │   かつ その画数で完結する字形しか無い   → その場で確定（待ち時間ゼロ）
   │    └─ ② それ以外 → 「書き足し待ち」タイマーを開始（既定 400ms）
   └─ 待ち時間内に次の1画が始まれば → タイマー解除して書き足しを継続
       待ち時間が経過したら       → その時点の1位候補で確定
```

| 設定 | 選択肢 | 既定 |
| --- | --- | --- |
| 書き足し待ち時間 | 200 / 300 / 400 / 600 / 800 / 1000 ms | **400ms** |
| 即確定 | ON / OFF（OFFなら常に待ち時間で確定） | ON |
| 即確定しきい値 | ゆるい / ふつう / きびしい | ふつう |

- 「即確定」で確定した直後 **600ms 以内**に新しい画が始まった場合は、**直前の確定を取り消して**
  書き足しとして扱う（例：`ノ` を確定した直後に2画目を書いて `メ` にする）。取り消し時は
  読み上げ中の音声を止め、入力中の行からも削除する。この救済のことを「**書き足しリカバリ**」と呼ぶ。
- 1文字が確定したら、キャンバスの筆跡は消える（3.3）。

### 4.2 認識エンジン（外部依存なし・オフライン）

| 項目 | 仕様 |
| --- | --- |
| 方式 | **画数つき点群マッチング（$P+ / $N 系の改良）** ＋ 画数・筆順・方向特徴によるフィルタ |
| 前処理 | ①各画を等間隔に再サンプリング（1画 32点） ②全画まとめて重心を原点へ ③最大辺で正規化（縦横比は保持、極端に細長い字＝`ー` `一` を守る） |
| 照合 | 候補テンプレートとの点群距離（Greedy Cloud Match）＋ 各画の始点／終点／主方向の一致度 |
| 画数 | テンプレートの画数と一致するものを優先。1画少ない／多いものは減点のうえ候補に残す（書き足し待ちのため） |
| テンプレート | カタカナ46字＋`ー`＋数字10字について、標準字形を **1字あたり2〜4種**（続け字・略字・筆順違いを含む）内蔵 |
| 出力 | 上位3候補（文字＋スコア 0〜1） |
| 実装 | 100% JavaScript、モデルファイル無し、CDN 無し |

#### 4.2.1 まぎらわしい字への対策

| 組 | 判別の手がかり |
| --- | --- |
| `ロ` / `0` | `0` は丸み（角の少なさ）と縦長、`ロ` は角ばりと横長 |
| `ニ` / `二`(数字なし) / `=` | `ニ` は上短・下長 |
| `ソ` / `ン` | 1画目の方向（`ソ`＝左下へ、`ン`＝右下へ）と2画目の角度 |
| `シ` / `ツ` | 3画目（払い）の向きと、1〜2画目の並び方向 |
| `ク` / `タ` / `7` | 画数（1/3/1〜2）と内部の払いの有無 |
| `ス` / `7` / `フ` | 画数と2画目の有無 |
| `1` / `ー` / `｜` | 主方向（縦／横）とアスペクト比 |
| `メ` / `×` | `×` は非対象（メとして扱う） |
| `エ` / `工` | 同字形。カタカナ `エ` として扱う |

- 設定「**数字をつかう**」を OFF にすると数字テンプレートを候補から外し、カタカナだけで判定する
  （数字を使わない会話が続くときの精度向上のため。既定 ON）
- 逆に「**数字だけモード**」（電話番号・時刻の入力時）も用意する

### 4.3 候補の表示と訂正

| 項目 | 仕様 |
| --- | --- |
| 候補バー | 入力中の行のすぐ下（キャンバス上端）に、**第2・第3候補**を小さなチップで最大2つ表示 |
| 表示時間 | 直前の確定から **4秒**（設定で 出さない / 3 / 5 / 10秒） |
| 操作 | チップをタップ → 直前の1文字を差し替え、差し替えた文字を発音 |
| 自信が低いとき | 1位スコアがしきい値未満の場合は、確定した文字を**黄色の下線**で表示（「あやしい」印） |
| 認識できないとき | 何も発音せず、キャンバスを揺らす（120ms）＋「もういちど かいてね」を1.5秒表示。筆跡は消す（設定で「消さずに残す」も可） |

### 4.4 削除ジェスチャ（ジグザグ）

| 項目 | 仕様 |
| --- | --- |
| 判定 | **1画のみ**で、①主方向が横 ②x方向の折り返しが **3回以上** ③総移動距離がマスの対角の 1.2倍以上 ④各折り返しの振幅がマス幅の 15% 以上 |
| 判定タイミング | その画を書き終えた瞬間（`pointerup`）。**書き足し待ちより優先** |
| 動作 | ①書きかけの筆跡があれば破棄（＝書き直し）／無ければ入力中の行の末尾1文字を削除 ②**「削除」と発音** ③削除した文字を 300ms 赤く表示してから消す |
| 行が空のとき | 発音は「けすものが ありません」（設定でOFF可）。ログは消さない |
| 誤爆対策 | `シ` `ツ` `ミ` `サ` など折り返しの多い字と競合しないよう、**折り返し3回以上かつ1画**に限定。しきい値は設定で ゆるい／ふつう／きびしい |
| 長いジグザグ | 折り返しが **6回以上**なら「ぜんぶけす」とみなす（確認トーストを出し、3秒以内に「もどす」で復帰）※採否は Q6 |

## 5. 音声出力

| 項目 | 仕様 |
| --- | --- |
| エンジン | Web Speech Synthesis API（`speechSynthesis`）。オフラインで動作 |
| 言語 | `ja-JP` |
| 声 | **女性の声**を優先自動選択（`Kyoko` / `O-ren` / 名前に `Female` を含む ja-JP ボイス → 見つからなければ ja-JP の先頭）。設定で手動選択も可 |
| 1文字の発音 | 確定した瞬間に、その1文字だけを読み上げる（例：「ア」） |
| 連続入力時 | 速く書いても取りこぼさないよう **`cancel()` せずにキューへ積む**（設定「はやく書いたら前の声を止める」でキャンセル方式にも変更可） |
| 発音の調整 | カタカナ1文字はそのまま読ませると不自然な字がある（`ハ`＝「は」、`ヘ`＝「へ」、`ヲ`＝「を」、`ン`＝「ん」等）。**読み辞書**を内蔵して自然な音にする |
| 数字 | 1文字ずつ「いち」「に」…と読む（`0`＝「ぜろ」） |
| 削除 | 「削除」（`サクジョ`） |
| 行の読み上げ | ［よみあげ］ボタンで行全体を読む。**長音・促音を含む自然な読み**になるよう、そのままの文字列を渡す |
| 速度・高さ | 速度：遅い(0.8) / ふつう(1.0) / 速い(1.2)、高さ：低い(0.9) / ふつう(1.0) / 高い(1.1) |
| 読み上げOFF時 | 文字認識・表示・ログは動くが、音声は出さない |
| iOS の制限 | 初回のユーザー操作までは音声が鳴らないため、起動後に1度だけ「がめんを さわってはじめる」オーバーレイを出す（Asa-Com と同じ考え方） |

## 6. 文（行）の確定とログ

| 項目 | 仕様 |
| --- | --- |
| 行の確定 | ［かくてい］ボタン（入力中の行の右）を押すと、その行をログへ1件追加し、行を空にする |
| 自動確定 | 設定「**書き終わりで自動確定**」ON のとき、最後の入力から **20秒**（10/20/30/60秒）無操作で自動確定 |
| 確定時の動作 | 行全体を読み上げ（設定でOFF可）→ ログに追加 → 入力中の行をクリア |
| 記録内容 | 日時（ISO 8601）、表示時刻（HH:MM）、種別（`text`）、本文 |
| 保存先 | `localStorage`（キー：`asacom2.log`） |
| ログOFF時 | 表示せず・保存せず・書き出し対象にもしない（Asa-Com と同じ） |
| 書き出し | 設定から CSV（`asacom2_log_YYYYMMDD.csv`） |
| 消去 | 設定から「ログを消去」（確認ダイアログあり） |

#### CSV フォーマット

```csv
datetime,time,type,text
2026-09-22T10:15:32+09:00,10:15,text,オチャ ノミタイ
2026-09-22T10:19:41+09:00,10:19,text,テレビ 7
```

### 7.1 「手書きをおぼえさせる」（任意機能・採否は Q3）

本人の書き方のクセを登録して精度を上げる機能。

- 練習画面で「ア」から順に表示される文字を書く（1字につき1〜3回）
- 登録した筆跡はテンプレートに**追加**され、以後の認識で優先的に照合される
- 保存先：`localStorage`（キー：`asacom2.ink`）。書き出し／読み込み（JSON）も可能
- 全部を登録する必要はなく、**まちがえやすい字だけ**を登録できる（一覧から選択）

## 8. 技術仕様

| 項目 | 内容 |
| --- | --- |

| ファイル構成 | `asa-com2/index.html` 単一ファイル（CSS/JS/テンプレートすべてインライン） |
| 外部依存 | なし（アイコンはインラインSVG、認識テンプレートはJSリテラル） |

| 想定解像度 | iPad 10.9"/11"（1180×820）を基準、12.9"（1366×1024）／mini（1133×744）に追随 |

### 8.1 データ構造

```js
// 設定
{
  strokeGapMs: 400, fastCommit: true, strictness: 'normal',
  useDigits: true, digitsOnly: false, candidateMs: 4000,
  zigzag: 'normal', zigzagClearAll: false,
  penWidth: 'mid', guide: 'cross',
  fontScale: 'normal', logRatio: 'normal', showKeys: true, highContrast: false,
  speak: true, voiceURI: null, rate: 1.0, pitch: 1.0, sound: true, cancelPrev: false,
  autoCommitMs: 20000, speakOnCommit: true, logEnabled: true,
  keepAwake: true, gearGuard: false
}

// ログ1件
{ id:'a1b2c3', datetime:'2026-09-22T10:15:32+09:00', type:'text', text:'オチャ ノミタイ' }

// 認識結果
{ char:'ア', score:0.87, alts:[{char:'マ',score:0.61},{char:'ヤ',score:0.55}] }

// 登録筆跡（おぼえさせる）
{ char:'ア', strokes:[[{x,y},…],[…]], ts:1758500000000 }
```

### 8.2 アクセシビリティ

- 補助キー・トグルには `aria-label`、ログエリアに `role="log" aria-live="polite"`
- 入力中の行は `aria-live="polite"`（VoiceOver 併用時の二重読みを避けるため、読み上げON時は `aria-live="off"`）
- `prefers-reduced-motion` 指定時はアニメーション（カーソル点滅・揺れ）を停止
- フォーカスリング 4px（`#1A73E8`）、スイッチコントロールで補助キーを走査可能
